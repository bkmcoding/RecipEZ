# Four-Model Comparison

This report compares the four static model modes used by the current RecipEZ frontend. Every mode receives the same recipe IDs and metadata, but each defines similarity from a different feature representation.

## Dataset Profile

| Property | Value |
| --- | ---: |
| Sampled recipes | 30,000 |
| Ontology clusters represented | 21 |
| Unique ingredient strings | 8,436 |
| Precomputed neighbors per recipe | 5 |

## Core Model Metrics

| Model | Neighbor tag purity | Ingredient Jaccard | 3D silhouette | 3D/semantic overlap |
| --- | ---: | ---: | ---: | ---: |
| TF-IDF | 0.5995 | 0.1143 | -0.1185 | 0.1248 |
| SBERT Combined | 0.5406 | 0.1182 | -0.1367 | 0.1421 |
| SBERT Ingredients | 0.3704 | 0.1785 | -0.1618 | 0.1031 |
| SBERT Names | 0.4553 | 0.0969 | -0.1627 | 0.1533 |

## Distinctiveness

Distinctiveness is `1 - mean pairwise neighbor overlap`. A value near 1 means a mode tends to retrieve a materially different five-recipe neighborhood.

| Model | Distinctiveness |
| --- | ---: |
| TF-IDF | 0.9613 |
| SBERT Combined | 0.8880 |
| SBERT Ingredients | 0.9698 |
| SBERT Names | 0.9052 |

SBERT Ingredients and TF-IDF are the most independent from the other modes. SBERT Combined is the least independent because it shares its strongest overlap with SBERT Names.

## Pairwise Neighbor Overlap

| Model pair | Mean overlap |
| --- | ---: |
| SBERT Combined × SBERT Ingredients | 0.0417 |
| SBERT Combined × SBERT Names | 0.2367 |
| SBERT Combined × TF-IDF | 0.0578 |
| SBERT Ingredients × SBERT Names | 0.0191 |
| SBERT Ingredients × TF-IDF | 0.0297 |
| SBERT Names × TF-IDF | 0.0288 |

Most model pairs retrieve materially different neighborhoods. The strongest relationship is between SBERT Combined and SBERT Names; every other pair remains below `0.06` mean overlap.

## Ontology-Cluster Behavior

The two cluster heatmaps expose where model behavior converges and diverges:

- **Dessert Core is consistently the strongest cluster.** Neighbor tag purity ranges from `0.7099` for SBERT Ingredients to `0.8437` for TF-IDF.
- **Cake Nebula has the highest ingredient overlap in every mode.** The peak is `0.3257` for SBERT Ingredients, making it the most ingredient-literal region of the galaxy.
- **Sparse clusters are unstable.** Baking Sector, Stew Cluster, and Indian Cuisine contain only 20–40 recipes and should not be treated as reliable cluster-level conclusions.
- **Ingredient similarity does not imply ontology similarity.** For SBERT Ingredients, Cake Nebula has only `0.1387` tag purity but `0.3257` ingredient Jaccard.

## Findings

1. **Model choice materially changes retrieval.** Five of six model pairs have mean neighbor overlap below `0.06`.
2. **TF-IDF aligns most closely with the current tag ontology.** Its `0.5995` global tag purity and `0.8437` purity in Dessert Core are the strongest ontology agreements.
3. **SBERT Ingredients is the most literal ingredient model.** It has the highest global ingredient Jaccard at `0.1785` and the highest distinctiveness at `0.9698`.
4. **SBERT Names is concept-oriented.** It has the lowest ingredient overlap, the highest 3D/semantic overlap, and a visible relationship with combined SBERT.
5. **The 3D galaxy is exploratory rather than a ranking surface.** All silhouette scores are negative, and 3D/semantic overlap remains between `0.10` and `0.16`.
6. **The four modes are useful as an ablation suite, not as redundant alternatives.** Their low cross-model overlap confirms that each feature representation captures a different notion of recipe similarity.

## Methodology Caveat

The ontology is a visualization aid derived from tags, not a manually verified relevance ground truth. These metrics compare model behavior against available labels and ingredient sets; they do not claim human-level preference accuracy.
