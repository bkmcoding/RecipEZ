# Legacy Archive

This directory preserves the previous RecipEZ iterations. Nothing from the legacy work was deleted during the restructuring.

| Path | Contents |
| --- | --- |
| `docs.md` | Original unfinished documentation draft |
| `app/` | Older `main/` application and model-generation scripts |
| `testing/` | Former `old_testing/` experiments and datasets |
| `presentation/` | Previous Typst documents, presentations, and diagnostic plots |
| `legacy/` | Remaining former `RAW_recipeTest/` assets, model payloads, and older interfaces |

The current canonical application is in [`web/`](../web/index.html), and the current model builder is in [`pipeline/`](../pipeline/build_models.py).
