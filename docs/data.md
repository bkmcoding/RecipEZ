# Dataset and Generated Artifacts

## Raw Dataset

The current pipeline expects:

```text
data/raw/RAW_recipes.csv
```

`data/raw/` is the single location for all raw CSV exports, including optional source files that are not consumed by the current builder.

The source dataset is [Food.com Recipes and Reviews](https://www.kaggle.com/datasets/shuyangli94/food-com-recipes-and-reviews) by Shuyang Li.

The builder loads all rows and deterministically samples 30,000 records using `random.seed(42)`.

## Generated Model Bundles

Generated files are ignored by Git because they are large and reproducible:

```text
web/model_data/sbert_all_data.json
web/model_data/sbert_ingredients_data.json
web/model_data/sbert_names_data.json
web/model_data/tfidf_data.json
```

To regenerate them:

```bash
python pipeline/build_models.py
```

## Research Artifacts

The evaluation script writes `research/metrics.json` and eight generated figures:

```text
research/figures/neighbor_tag_purity.png
research/figures/ingredient_jaccard_similarity.png
research/figures/semantic_vs_geometry_overlap.png
research/figures/model_neighbor_overlap_heatmap.png
research/figures/model_behavior_radar.png
research/figures/cluster_tag_purity_heatmap.png
research/figures/cluster_ingredient_overlap_heatmap.png
research/figures/galaxy_projection_gallery.png
```

The retained `research/figures/pca_vs_umap.png` is a legacy diagnostic and is not regenerated by the current evaluation script.

To regenerate the current metrics and figures:

```bash
python pipeline/evaluate_models.py
```

## Ignored Directories

`.gitignore` currently ignores:

- `data/raw/`
- `data/processed/`
- `web/model_data/`
- `old/legacy/`

This keeps large datasets and generated payloads out of version control while preserving them locally.
